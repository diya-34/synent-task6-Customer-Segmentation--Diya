# 🛍️ Customer Segmentation Analysis using K-Means Clustering

### 👩‍💻 Internship Project – Synent Technologies

## 📌 Project Overview

This project focuses on Customer Segmentation using the Mall Customer Dataset.

The objective is to group customers based on their purchasing behavior using Machine Learning techniques. K-Means Clustering is used to identify meaningful customer groups based on Annual Income and Spending Score.

The generated customer segments help businesses understand customer behavior and create targeted marketing strategies.

## 🎯 Objective

- Perform Data Preprocessing
- Apply K-Means Clustering
- Visualize Customer Segments
- Generate Business Insights
- Create Customer Recommendations

## 📊 Dataset Information

**Dataset:** Mall Customer Dataset

### Features

|----------|------------|

| Gender | Male/Female |
| Age | Customer Age |
